## Requirements
- Node >= 20

## Getting Started
- install biasa aja pake ```bash npm install```
- npm run build & npm run start

## Notes
- kalau mau tambah fetch di chart tinggal ke devices-charts dan jangan lupa defineProps untuk ambil nilai date
- devices container untuk menampilkan data device dan tinggal tambah API di fastify (sama untuk devices charts juga)
- toggle button ada di devices/index.vue (nanti tinggal pakai id atau nama. bebas)
- contoh bentuk data (bisa liat di components/devices/devices-charts) : 
```js
{
    name: "CO2 Levels",
    data: [10, 40, 35, 50, 49],
},
```
